# 注射系统重构实现任务

- [x] 1. 建立核心数据组件与注册骨架
  - 注册 `LOADED_AMPOULE`、`USED_DOSES` 和药剂包内容组件。
  - 注册注射枪、通用原版药水安瓿和药剂投射物。
  - 保持现有 `*_injection` 注册 ID，并把实现类型迁移为安瓿。
  - 接入主模组初始化，保持客户端类与通用初始化隔离。
  - _需求：R1、R2、R6_

- [x] 2. 重构安瓿与药效服务
  - 实现不可直接使用、普通堆叠上限为 16 的 `AmpouleItem`。
  - 把现有八种药剂的普通与特殊效果迁移到 `MedicineEffectService`。
  - 实现带 `POTION_CONTENTS` 的通用原版药水安瓿效果。
  - 保留冷却、声音、统计、饥饿副作用与过量使用记录。
  - 移除旧注射器的直接使用、食用和绕过注射枪的路径。
  - _需求：R2、R6_

- [x] 3. 实现注射枪状态与确定性容量
  - 实现枪膛安瓿的读取、写入、清空和合法性检查。
  - 实现基础 64 次容量以及耐久Ⅰ/Ⅱ/Ⅲ对应的 80/96/112 次容量。
  - 接受 `minecraft:unbreaking`（简中“耐久”）附魔，但不使用其随机免伤算法。
  - 实现动态耐久条、容量提示和达到容量后的物品损坏。
  - 验证空枪操作不消耗容量，药剂使用始终消耗一发。
  - _需求：R1-1、R1-2、R1-15 至 R1-19_

- [x] 4. 重构药剂包存储
  - 实现固定 9 槽、只接受安瓿、每槽内部上限 64 的 handler。
  - 禁止包套包和非法物品进入。
  - 修复普通点击、拖动、数字键、shift-click 和满背包取出行为。
  - 保持包移动、丢弃、死亡掉落和饰品装备时的内容。
  - 实现旧 `CUSTOM_DATA/SyringeBag` 数据的一次性兼容迁移。
  - _需求：R3_

- [x] 5. 实现弹药来源解析与无损换弹事务
  - 按 Curios 腰带药剂包、物品栏药剂包、快捷栏、主物品栏的顺序扫描。
  - 聚合“物品 + 完整组件”相同的安瓿及数量。
  - 实现短按 `R` 选取第一发药剂。
  - 实现旧枪膛安瓿退回、新安瓿取出与写入的预检、模拟和原子提交。
  - 覆盖枪空、来源变化、库存已满、相同药剂和恶意选择等边界。
  - _需求：R1-3 至 R1-11、D1_

- [x] 6. 把 Curios 改为安全的可选兼容
  - 调整 Gradle 依赖与 `neoforge.mods.toml`，使未安装 Curios 时可启动。
  - 通过通用 bridge 与隔离实现访问 Curios API，避免缺失类加载。
  - 把药剂包接入标准 `belt` 槽。
  - 迁移或移除旧 `injection_kit` 自定义槽数据。
  - 分别验证安装与未安装 Curios 的构建和启动路径。
  - _需求：R3-7、R3-8、R6-3_

- [x] 7. 实现服务器权威的网络操作
  - 将协议版本提升为 `"2"`。
  - 实现自我注射、射击、快速换弹、快速注射和轮盘指定换弹 payload。
  - 对物品、组件、动作状态、冷却、频率和真实来源进行服务端复验。
  - 实现动作动画的 clientbound 同步消息。
  - 验证重复包、伪造安瓿、快速切换和多人状态不会复制或重复施药。
  - _需求：R1-20、R1A、R1B、R6_

- [x] 8. 实现输入、瞄准和 `R` 药剂轮盘
  - 注册可重绑的 `R` 换弹键，并只在主手持注射枪时工作。
  - 区分短按快速换弹与长按 8 tick 打开轮盘。
  - 拦截主手注射枪的左键：未瞄准开始自注射，右键瞄准时射击。
  - 实现不暂停世界、显示鼠标光标、每页 8 项、滚轮翻页、点击确认与取消的轮盘 Screen。
