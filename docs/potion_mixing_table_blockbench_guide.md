# 药剂混合台 Blockbench 精确建模操作说明书

## 1. 任务目标

在 Blockbench 中构建一个适用于 Minecraft Java Edition 1.21.1 的药剂混合台方块模型。模型必须与参考图中的最终方案一致：

- 主体是一个中性冷白色实验工作台。
- 桌面中央偏后安装一个明显高于桌面的方形离心混合机。
- 离心机具有方形凹槽、十字形转子、四个正交安瓿槽和可开启透明玻璃盖。
- 桌面具有双瓶样品架、取样工具、折叠实验擦布、右侧安瓿托盘。
- 桌面左前方有紫色药剂污渍，右后方有青绿色药剂污渍。
- 正面具有深灰检修面板、把手、青色状态像素和两个方形控制键。
- 所有形状必须由长方体、方块和必要的平面组成。
- 不允许圆柱、球体、曲面、斜切面、倒角、平滑网格或高精度微型几何。

本说明书面向自动化建模 AI。不要自行改变主题、比例、部件位置或配色。

## 3. 项目格式和基础设置

### 3.1 Blockbench 项目

- 新建项目格式：`Java Block/Item`。
- 项目名称：`potion_mixing_table`.
- 纹理宽高基准：每张纹理 `16×16 px`。
- UV 模式：优先使用逐面 UV，不使用自动生成的高密度 Box UV。
- 网格吸附：主结构 `0.25` 模型单位；大型结构尽量使用 `0.5` 或整数单位。
- 像素密度：标准情况下 `1 个模型单位 = 1 个纹理像素`。
- 环境遮蔽：可以启用 Minecraft 原生环境遮蔽，但不得把软阴影烘焙进纹理。
- 所有旋转角必须符合 Java 方块模型约束：`-45°`、`-22.5°`、`0°`、`22.5°`、`45°`。
- 盖子动画枢轴保留在 `.bbmodel` 中；静态 JSON 导出时按目标姿态烘焙。

### 3.2 坐标系

- X 轴：左到右。
- Y 轴：下到上。
- Z 轴：前到后。
- 正面为北面，即较小的 Z。
- 方块逻辑占地：X `0–16`，Z `0–16`。
- 最低点：Y `0`。
- 开盖状态最高点：不超过 Y `16`。
- 模型中心：`[8, 8, 8]`。

```text

```


- 导出开盖、关盖两个静态 JSON，用方块状态切换；或

## 12. UV 制作规范

### 12.1 总规则

- 开启 Pixel Perfect。
- 禁止纹理插值。
- UV 边界尽量落在整数像素。
- 同样大小、同样材质的对称部件允许重叠 UV。
- 每个模型单位通常对应一个 UV 单位。
- 小于 1 单位的薄侧面至少分配 1 像素，不能使用亚像素模糊。
- 旋转几何仍保持相同像素密度，不因旋转放大纹理。
- 所有北、南、东、西面的像素方向必须一致，避免一面纹理倒置。

### 12.2 桌面 UV

`top_slab` 顶面单独使用 `potion_mixing_table_tabletop.png`。

建议顶面 UV：

```text
up: [0,0,16,15]
```

纹理朝向必须通过俯视图核对：

- 紫色污渍位于左前区域，大致对应模型 X `1–3.5`、Z `2–4.5`。
- 青绿色污渍位于右后区域，大致对应 X `13–15`、Z `9–11.5`。
- 污渍用硬边阶梯形像素块组成。
- 污渍不得画到离心机机座、托盘或桌体侧面。
- 如果 Blockbench 顶面 UV 的 V 方向与模型 Z 相反，只翻转顶面 UV，不移动几何。

### 12.3 白色机壳 UV

- 大面使用 2–3 个相邻冷白色像素形成轻微杂色。
- 杂色必须是纹理内部的像素变化，而不是不同方块分别使用不同白色纹理。
- 边缘像素比中央略亮，凹槽附近略暗。
- 不做连续明暗带。

### 12.4 深灰面板和转子 UV

- 外框使用中深灰。
- 内凹面使用蓝黑色。
- 轮毂中心只画方形暗部。
- 转臂上的安瓿槽阴影画成严格矩形。
- 不画圆形转子纹理。

### 12.5 玻璃 UV

`potion_mixing_table_glass.png` 必须为 RGBA：

- 中心大部分像素 Alpha 为 `32–64`。
- 边缘浅蓝灰像素 Alpha 为 `96–160`。
- 四角高光 Alpha 可为 `192–255`。
- Alpha 只使用少量离散档位，不使用连续渐变。
- 禁止在玻璃中心绘制大块不透明黑色。
- 玻璃背后的世界应能透过。

如果最终使用 `cutout` 而非 `translucent`，则只允许 Alpha `0/255`，用稀疏棋盘格模拟透明；优先保留真正半透明方案。

## 13. 贴图绘制顺序

严格按以下顺序工作：

1. 先给所有元素应用纯色占位材质。
2. 检查三视图轮廓和尺寸。
3. 完成白色机壳、桌面和深灰结构基础色。
4. 完成转子、安瓿和控制键颜色。
5. 绘制桌面紫色、青绿色污渍。
6. 绘制擦布中心图案。
7. 最后绘制玻璃透明纹理和角部高光。
8. 关闭纹理过滤，使用最近邻预览。
9. 在正常游戏观察距离检查，确保没有高分辨率噪点。

## 14. 开盖和关盖状态

主 `.bbmodel` 必须保存可旋转的 `lid` 组。

### 开盖状态

- `lid.rotation = [0,0,0]`
- 与参考三视图一致。
- 铰链位于机座后沿。
- 盖子玻璃垂直。

### 关盖状态

- 将 `lid` 围绕 `[8.2,9.75,13.05]` 沿 X 轴旋转 `-90°`。
- 盖框应覆盖离心机外框，不能覆盖样品架、擦布或右侧托盘。
- 玻璃中心应位于转子上方。
- 盖子底边不得落到白色桌面。

导出建议：

```text
models/block/potion_mixing_table_open.json
models/block/potion_mixing_table_closed.json
```

如果目前只导出一个模型，以通过的开盖参考图为默认输出，并保留 `.bbmodel` 供后续制作关闭状态。

目标路径：


物品模型：

```json

}
```

玻璃渲染：

- `lid_glass` 与不透明主体分组。
- 若整个模型采用单一 JSON，则客户端为该方块启用 translucent 渲染层。
- 更稳妥的方案是把玻璃导出为单独模型层，再通过 multipart/composite 组合。
- 粒子纹理使用不透明的机壳或深灰面板纹理，禁止使用透明玻璃纹理。

方块朝向：

- 如果方块支持水平朝向，模型原始北面必须是正面检修面板。
- blockstate 中只通过 Y 轴旋转 `0/90/180/270°`。
- 不为每个朝向复制完整模型。

## 16. 性能和几何清理

- 目标元素数量：尽量控制在 `70` 个以内。
- 不为污渍、螺丝、槽内阴影、擦布图案创建几何。
- 删除完全位于其他方块内部的隐藏面。
- 避免共面或仅相差 0 的叠层。
- 玻璃只使用一个薄元素。
- 每个安瓿最多使用药液体、玻璃/瓶体、端帽三段。
- 不使用网格、圆柱和细分曲面。
- 不为装饰几何制作同等复杂的碰撞箱。

建议游戏碰撞：

1. 主体大箱：X `0–16`、Y `0–8`、Z `0.5–15.5`。
2. 离心机箱：X `3.35–13.05`、Y `8–10.3`、Z `4.85–13.05`。
3. 开盖时可选增加后部薄箱；如果影响玩家交互，可不纳入碰撞。
