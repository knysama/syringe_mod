# 注射枪 Blockbench 精确建模操作说明书

版本：1.0  
适用工程：Minecraft Java Edition 1.21.1 / NeoForge 21.1  
模组 ID：`syringe_mod`  
目标物品：`injection_gun`  
三视图参考：[空仓注射枪三视图](reference/injection_gun_three_view_empty.png)

---

## 1. 文档用途与执行优先级

本说明书用于让 Blockbench AI 按已确认的三视图构建注射枪。执行时按以下优先级处理冲突：

1. 本文列出的硬性造型、坐标、空仓状态和 UV 规则。
2. 三视图中的整体轮廓、部件位置和配色关系。
3. AI 对遮挡区域的合理补全。

不得因“更真实”“更科幻”或“更像枪”而擅自添加曲面、圆柱、瞄具、弹匣、枪托、导轨齿、医疗十字、文字或高精度零件。

最终模型必须首先被识别为“使用安瓿药剂的注射枪”，而不是治疗枪、普通手枪或能量武器。

## 2. 最终交付物

必须保留以下文件：

```text
docs/modeling/injection_gun.bbmodel
src/main/resources/assets/syringe_mod/models/item/injection_gun_empty.json
src/main/resources/assets/syringe_mod/models/item/injection_gun_loaded.json
src/main/resources/assets/syringe_mod/textures/item/injection_gun.png
src/main/resources/assets/syringe_mod/textures/item/injection_gun_glass.png
src/main/resources/assets/syringe_mod/textures/item/injection_gun_fluid.png
```

其中：

- `injection_gun.bbmodel` 是可继续编辑的源工程。
- `injection_gun_empty.json` 是默认模型，药仓必须为空。
- `injection_gun_loaded.json` 只比空仓模型多一个内部药剂体。
- `injection_gun.png` 是不透明外壳、握把、针头和金属件贴图。
- `injection_gun_glass.png` 是带 Alpha 的药仓玻璃贴图。
- `injection_gun_fluid.png` 是装弹状态的白色/灰白色染色遮罩；实际药剂颜色由游戏端决定。

不要把 `.bbmodel` 放进最终 JAR。当前 Gradle 已排除该格式。

## 3. 美术硬约束

### 3.1 几何

- 只能使用无旋转的长方体、正方体和必要的二维矩形面。
- 所有元素的 Rotation 必须为 `[0, 0, 0]`。
- 禁止 Mesh、圆柱、球体、斜面、倒角、圆角、曲线和倾斜切面。
- 枪柄的后倾感只能用三段直角阶梯实现。
- 针头必须是短而细的方杆，截面为 `1 × 1` 模型单位。
- 所有坐标优先为整数，禁止为了“更平滑”使用密集的 0.1 或 0.25 单位微型方块。
- 不允许存在共面重叠面；相邻方体可以贴合，但不能让两张面占据同一平面。

### 3.2 像素密度

- 纹理图可使用 `64 × 64`，但像素密度必须保持为：

```text
1 Blockbench 模型单位 = 1 纹理像素
16 模型单位 = 16 纹理像素 = 1 个标准 Minecraft 方块
```

- 所有 UV 坐标必须吸附到整数像素。
- 一个尺寸为 `8 × 2` 模型单位的面必须占用 `8 × 2` 纹理像素，不得放大到 `16 × 4`。
- 禁止 MIXELS：同一模型内不得让某些部件拥有更高像素密度。
- 禁止抗锯齿、柔边、模糊、连续渐变和照片材质。

### 3.3 默认状态

- 默认注射枪为未装弹状态。
- 空仓内不得出现青色液体、安瓿、药芯或发光块。
- 透明观察窗只能看到空腔和少量方形玻璃高光。
- 青色液体只能出现在 `loaded_fluid` 组启用的装弹模型中。

## 4. Blockbench 工程设置

1. 新建 `Java Block/Item` 工程，不要创建实体模型或自由模型。
2. 工程名设为 `injection_gun`。
3. Texture Width 和 Texture Height 均设为 `64`。
4. UV 模式使用逐面 UV，不使用会自动缩放像素密度的自适应 UV。
5. 将三视图作为 Reference Image 导入，不要把参考图本身导入为纹理。
6. 关闭平滑着色；所有面保持硬边和平面光照。
7. 开启网格吸附，主网格步长设为 `1`。
8. 工程中心和默认显示旋转中心设为 `[12.5, 8, 8]`。

如果 AI 通过 Blockbench MCP 操作：

1. 先创建一个名为 `mcp_connection_test` 的 `1 × 1 × 1` 测试方块。
2. 检查 Outliner 中确实出现该方块。
3. 立即撤销或删除测试方块。
4. 在正式建模前创建一次检查点。
5. 灰模、UV、贴图完成后各创建一次检查点并截图核对。

## 5. 坐标系、方向与整体边界

统一使用以下方向：

```text
X-：枪口、针头方向
X+：枪尾、推入栓方向
Y+：上方
Y-：握把底部
Z-：左侧面（三视图的主要展示面）
Z+：右侧面
```

主要边界：

```text
针头最前端：X = 0
主体前端：X = 3
主体后端：X = 15
推杆末端：X = 25
握把底部：Y = 0
顶部最高点：Y = 16
主体基本厚度：Z = 5 至 11
侧面突起最大厚度：Z = 4 至 12
```

不含针头和推杆时，主体可见长宽比应约为 `18 : 7`。整体包围盒约为 `25 × 16 × 10`；不得压缩成近方形，也不得把枪体翻倍拉成长枪比例。

## 8. 几何优化与面处理

完成所有方体后执行以下检查：

1. 删除永久被相邻实体完全遮挡的内部面。
2. 保留玻璃腔体需要透视的内侧面。
3. 不要为了螺丝、接缝、通风孔和细划痕增加方体。
4. 铜色方钉、外壳接缝、上/下凹槽全部优先画入贴图。
5. 不要让面与面仅相差 `0.001` 单位来避免冲突；应重新安排几何边界。
6. 目标方体数量约为 35–45 个。
7. 优化后目标可见面数量控制在约 120–180；若明显超出，先把小型硬件改成贴图。

模型是单件手持英雄道具，可以比普通方块复杂，但不得使用微型方体绘制像素。

## 10. UV 与贴图操作

### 10.1 贴图文件

创建三张贴图：

```text
injection_gun.png        64 × 64，RGBA，不透明主体
injection_gun_glass.png  16 × 16，RGBA，透明玻璃
injection_gun_fluid.png  16 × 16，RGBA，药剂染色遮罩
```

### 10.2 主贴图分区建议

`injection_gun.png` 使用以下逻辑区域；允许在区域内共享和重复 UV：

| 像素区域 | 内容 |
|---|---|
| `0–15, 0–15` | 白色主体基础面 |
| `16–31, 0–15` | 白色错层护板与顶部突起 |
| `32–47, 0–15` | 深灰框架、护圈和推杆 |
| `48–63, 0–15` | 握把嵌片 |
| `0–15, 16–31` | 黄铜方钉、卡扣和按钮 |
| `16–31, 16–31` | 针头与浅灰金属 |
| `32–47, 16–31` | 凹槽、接缝和深部阴影 |
| `48–63, 16–31` | 备用状态纹理 |
| `0–63, 32–63` | 长边、顶面、底面和后续微调区域 |

分区是组织建议，不代表把每个面拉伸到整个 16 像素区域。

### 10.3 每面 UV 规则

1. 每个面的 UV 宽高必须等于该面的模型单位宽高。
2. 例如 `rear_shell_core` 的左侧面尺寸为 `3 × 7`，其 UV 必须恰好占 `3 × 7` 像素。
3. 长条面允许横向排布，但不得缩放纹理密度。
4. 对称左右面可以共享 UV。
5. 同材质、同尺寸的重复方体可以复用 UV。
6. 顶面统一比侧面亮一级；底面统一比侧面暗一级。
7. X- 朝向的前端面略亮，X+ 后端面略暗，形成固定的左前上光源。
8. 明暗转换只能用硬色块或极少量棋盘格抖动，不得使用渐变工具。
9. 所有 UV 岛之间至少留 1 像素空隙，减少 mipmap 串色。
10. Paint Settings 必须开启 `pixel_perfect`，笔刷尺寸固定为 1 像素，Softness 为 0。

### 10.4 需要画入贴图而非建模的细节

- 白壳上的分段接缝。
- 顶部和底部的横向凹槽。
- 黄铜方钉和方形固定件。
- 握把上的两至三条粗防滑分区。
- 针头根部的一圈深灰连接色。
- 加载卡扣中央的黄铜按钮。
- 玻璃上的四个稀疏方形高光。

每个细节的最小尺寸为 1 像素，不得出现半像素和抗锯齿像素。

## 13. 导出与工程接入

### 13.1 Blockbench 导出

1. 保存源工程为：

```text
docs/modeling/injection_gun.bbmodel
```

2. 隐藏 `loaded_fluid`，导出空仓模型：

```text
src/main/resources/assets/syringe_mod/models/item/injection_gun_empty.json
```

3. 显示 `loaded_fluid`，导出装弹模型：

```text
src/main/resources/assets/syringe_mod/models/item/injection_gun_loaded.json
```

4. 检查 JSON 中所有纹理引用使用：

```text
syringe_mod:item/injection_gun
syringe_mod:item/injection_gun_glass
syringe_mod:item/injection_gun_fluid
```

5. 不得引用绝对磁盘路径。

### 13.2 当前工程的覆盖风险

当前数据生成器会把 `injection_gun` 生成为继承 `minecraft:item/handheld` 的二维临时模型，并复用 `cure_injection` 贴图。正式接入三维模型时必须同步调整：

```text
src/main/java/cn/autoforged/syringe_mod/datagen/ModItemModelProvider.java
```

不要继续生成旧的二维 `injection_gun.json`，否则运行 datagen 后可能覆盖或冲突。

最终状态选择需要在客户端模型系统中根据 `loaded_ampoule` 组件切换：

```text
空：injection_gun_empty
非空：injection_gun_loaded
```

这一步属于代码接入，不由 Blockbench 自动完成。

## 14. 分阶段执行流程

AI 必须按以下顺序工作，不得先画贴图再改主体比例：

### 阶段 A：灰模

1. 创建分组和枢轴。
2. 只建立白色主体、短针、推杆、握把和扳机护圈。
3. 用纯灰色材质预览侧视、正视、顶视。
4. 对照三视图检查长度、高度和厚度。
5. 截图并创建检查点。

### 阶段 B：二级轮廓

1. 加入顶部突起。
2. 加入前后错层护板。
3. 加入药仓外框。
4. 加入握把嵌片与装填卡扣。
5. 确认没有曲面、旋转方体和过密小零件。
6. 截图并创建检查点。

### 阶段 C：空仓

1. 建立单一透明玻璃方体。
2. 保持 `loaded_fluid` 隐藏。
3. 从侧面确认玻璃内部为空。
4. 从顶部确认玻璃与框架厚度一致。

### 阶段 D：UV

1. 建立三张贴图。
2. 先展开白壳，再展开深灰结构、握把和针头。
3. 玻璃与药剂体使用独立贴图。
4. 检查每个 UV 岛的像素密度。
5. 禁止任何 UV 自动缩放到填满画布。

### 阶段 E：像素贴图

1. 铺主色。
2. 按固定光源绘制顶亮、侧中、底暗。
3. 绘制凹槽、接缝和黄铜方钉。
4. 绘制空玻璃的稀疏方形高光。
5. 不使用渐变、噪声或软笔刷。
6. 截图并创建检查点。

### 阶段 F：显示与导出

1. 调整七种 Display 变换。
2. 分别导出空仓和装弹模型。
3. 重新打开导出的 JSON，确认纹理路径有效。
4. 在 Minecraft 中检查 GUI、地面、第三人称和第一人称。

## 15. 最终验收清单

只有全部满足才算完成：

- [ ] 主体比例与三视图一致，没有过长或方胖。
- [ ] 主体颜色以白色和浅冷灰为主。
- [ ] 枪体顶部、底部和前后侧壳存在克制的阶梯与沟槽。
- [ ] 轮廓不是一个单一长方体。
- [ ] 针头短、细、方形，长度为 2 单位。
- [ ] 推杆粗且直接结束，没有尾部方块挡板。
- [ ] 握把通过三段直角阶梯形成后倾感。
- [ ] 扳机和方形护圈之间存在清晰空隙。
- [ ] 默认模型药仓为空。
- [ ] 装弹模型只增加内部药剂体。
- [ ] 未出现医疗十字、心形、文字或治疗枪标识。
- [ ] 未出现瞄具、弹匣、枪托或普通枪械标记。
- [ ] 全模型没有圆柱、球体、斜面、倒角和旋转方块。
- [ ] 所有 UV 坐标为整数。
- [ ] 所有表面保持 1 模型单位对应 1 像素。
- [ ] 透明玻璃没有白底，Alpha 通道有效。
- [ ] 不存在明显 Z-fighting、共面重叠和大面积隐藏面。
- [ ] GUI 中能同时辨认针头、观察窗、推杆、握把和扳机。
- [ ] 第一人称手部握持位置合理。
- [ ] `.bbmodel`、空仓 JSON、装弹 JSON和三张贴图均已保存。

## 16. 禁止 AI 自行发挥的项目

未经用户再次确认，AI 不得：

- 改变已确定的整体长宽比例。
- 加长针头。
- 在推杆尾部增加挡板。
- 把白色主体改回红白医疗配色。
- 在空仓中放置青色液体。
- 添加曲线扳机、圆柱针头或斜角握把。
- 为“丰富细节”增加大量螺丝方块和导轨齿。
- 使用 128×128 或更高分辨率制造微型细节。
- 把药仓做成圆管。
- 把模型改成治疗枪、科幻手炮或普通手枪。

如三视图与坐标表存在局部遮挡差异，应优先保持本文坐标表的可实现结构，并将差异记录下来，不得静默重设计。
