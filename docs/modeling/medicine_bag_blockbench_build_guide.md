# 药剂包 Blockbench 精确建模操作说明书

## 1. 任务目标

根据药剂包三视图，建立一套可用于 Minecraft Java Edition 模组的药剂包三维模型。模型必须同时具备关闭与打开状态，并可用于手持渲染和腰带饰品渲染。

主要参考图：

- `F:/Syringe/syringe_mod/docs/concepts/medicine_bag/medicine_bag_orthographic_views.png`
- `F:/Syringe/syringe_mod/docs/concepts/medicine_bag/medicine_bag_concept_v5.png`

现有物品栏贴图：

- 关闭：`assets/syringe_mod/textures/item/syringe_bag.png`
- 打开：`assets/syringe_mod/textures/item/syringe_bag_open.png`

三维模型不能覆盖上述二维物品栏资源。建议使用以下独立命名：

- Blockbench 主工程：`syringe_bag_model.bbmodel`
- 三维关闭模型：`syringe_bag_3d_closed`
- 三维打开模型：`syringe_bag_3d_open`
- 三维模型贴图：`syringe_bag_model.png`

## 2. 不可改变的设计原则

1. 药剂包是扁平、立式、顶开的硬壳腰包，不是横放的手提箱。
2. 宽度明显大于高度，高度明显大于厚度。
3. 大面积背面贴着玩家腰部，正面朝向玩家身体外侧。
4. 正面外壳固定，不允许向前或向下翻开。
5. 唯一可动部件是顶部窄盖。
6. 顶盖沿后侧长边铰接，打开时向上、向后旋转。
7. 内部药剂只排列一排，共五个展示位。
8. 正面中央是黑色卡扣，右下角是低饱和青色状态窗。
9. 两侧各有一个方形腰带挂环。
10. 所有结构只允许使用长方体、方块和必要的平面，不使用圆柱、球体、曲面、斜切面或倒角。
11. 除顶盖绕铰链旋转外，其他方块必须保持轴向对齐。
12. 关闭与打开状态必须使用完全相同的刚性零件尺寸，只改变顶盖旋转和药剂可见性。

## 3. Blockbench 项目设置

### 3.1 推荐格式

优先建立一个 `Generic Model` 主工程，以便保留组层级、任意角度枢轴和打开状态。

不要直接把主工程建立成普通的 `Java Block/Item` 并强行使用 70° 元素旋转。原版方块/物品 JSON 对元素旋转角度有限制，精确的约 70° 顶盖更适合由自定义物品/饰品渲染器读取，或者在导出前烘焙为独立打开模型。

物品栏仍使用现有二维贴图模型；三维模型只负责：

- 第一、第三人称手持显示；
- Curios 或其他腰带饰品栏的佩戴显示；
- 打开药剂包时的三维显示。

### 3.2 坐标系

统一采用以下方向：

- `X`：左右，正方向为模型右侧；
- `Y`：上下，正方向为模型顶部；
- `Z`：前后，正方向为玩家身体外侧；
- 后表面/贴身面：`Z = 6`；
- 正面：接近 `Z = 10`；
- 模型水平中心：`X = 8`。

主盒体外部范围：

- 宽：`X = 2` 至 `14`，共 12 单位；
- 高：`Y = 4` 至约 `11.5`；
- 厚：`Z = 6` 至 `10`，共 4 单位。

在 Blockbench 中启用：

- Position Snap：`0.25`；
- Rotation Snap：建模阶段 `22.5°`，设置顶盖最终姿态时允许输入精确角度；
- Texture Size：`32 × 32`；
- UV 模式：每面 UV，不使用自动拉伸后的混合像素密度；
- 插值与显示过滤：Nearest/最近邻。

## 6. 顶盖与铰链

### 6.1 枢轴

`lid` 组的 Origin/Pivot 必须设置为：

```text
(8, 10.75, 6)
```

该位置位于顶盖后侧长边的中心，正好对应贴身侧铰链。

### 6.2 顶盖方块

顶盖方块先按关闭状态建立：

| 元素名 | From | To | 说明 |
|---|---:|---:|---|
| `lid_shell` | `(2, 10.75, 6)` | `(14, 11.5, 10)` | 白色窄顶盖 |
| `lid_inner` | `(2.5, 10.6, 6.5)` | `(13.5, 10.75, 9.5)` | 顶盖内侧深灰嵌面 |

`lid_inner` 必须放入 `lid` 组并随顶盖一起旋转。关闭状态下，它位于顶盖下方，不应从外部明显穿出。

### 6.3 铰链

铰链不使用圆柱，使用方形铰链块：

| 元素名 | From | To | 所属组 |
|---|---:|---:|---|
| `hinge_body_left` | `(3, 10.25, 5.75)` | `(5, 11, 6.5)` | `hinge_body` |
| `hinge_body_right` | `(11, 10.25, 5.75)` | `(13, 11, 6.5)` | `hinge_body` |
| `hinge_lid_left` | `(3.25, 10.7, 5.75)` | `(4.75, 11.35, 6.5)` | `hinge_lid` |
| `hinge_lid_right` | `(11.25, 10.7, 5.75)` | `(12.75, 11.35, 6.5)` | `hinge_lid` |

允许铰链块轻微互相嵌套，但不得产生两张完全共面的表面。

### 6.4 打开角度

关闭状态：

```text
lid rotation X = 0°
```

打开状态：

```text
lid rotation X = -70°
```

这里以正面为 `+Z`。若当前 Blockbench 格式的旋转正负方向相反，应改用 `+70°`，但最终必须满足：

- 顶盖自由端向上移动；
- 顶盖向后侧铰链收拢；
- 顶盖不穿过正面外壳；
- 从正面能看到深灰色盖内面；
- 从侧面能清楚看到铰链旋转关系。

不要为了匹配角度而改变顶盖长度。

## 10. 32×32 材质与 UV

### 10.1 贴图原则

使用单张 `32 × 32` RGBA 贴图：

```text
assets/syringe_mod/textures/item/syringe_bag_model.png
```

32×32 是贴图画布尺寸，不代表提高像素密度。每个标准模型单位仍以约一个有效像素表达，避免在小面上绘制高分辨率微细节。

禁止：

- 自动抗锯齿；
- 平滑渐变；
- 高斯模糊；
- 噪点材质；
- 照片纹理；
- 亚像素线；
- 在同一个模型上混用不同清晰度的像素。

以下坐标以 32×32 贴图的实际像素为单位：

| 区域 | 像素范围 | 用途 |
|---|---:|---|
| A | `(0,0)–(12,7)` | 正面主面板 |
| B | `(0,7)–(12,14)` | 背面面板 |
| C | `(0,14)–(12,18)` | 顶盖外表面 |
| D | `(0,18)–(12,22)` | 顶盖深灰内表面 |
| E | `(12,0)–(16,7)` | 左右侧壁 |
| F | `(12,7)–(22,9)` | 内腔底面 |

| H | `(16,0)–(22,6)` | 石墨硬件通用区 |
| I | `(22,0)–(25,2)` | 青色状态窗 |

| K | `(12,10)–(24,14)` | 底面与不可见通用外壳面 |
| L | `(24,8)–(32,16)` | 铰链、挂环和卡扣的重复石墨纹理 |

允许多个相同材质的小面重叠使用同一个 UV 区域。不要为每个挂环方块绘制一套独立纹理。

### 10.4 关键面绘制

正面区域 A：

- 外圈使用外壳深边与阴影；
- 主区域使用外壳主体色；
- 顶边使用一条外壳高光；
- 底边使用一条外壳阴影；
- 不要把卡扣和状态窗直接画死在正面贴图里，因为它们已经是独立几何。

顶盖外表面区域 C：

- 主体为外壳高光和主体色；
- 沿宽度方向设置少量灰色分段线；
- 分段线最多一像素宽。

顶盖内表面区域 D：

- 使用石墨主体；
- 上沿一像素使用石墨高光；
- 下沿一像素使用最深轮廓；
- 不使用渐变。

药剂区域 J：

- 每种药剂至少保留一个清晰的纯色药液像素块；
- 帽部统一使用外壳高光；
- 不绘制反光渐变；
- 颜色顺序固定为红、橙、黄、绿、蓝。

### 10.5 UV 操作要求

1. 关闭 Box UV，切换到 Per-Face UV。
2. 所有 UV 边界必须落在整数像素。
3. 不允许将 1 像素纹理拉伸成模糊的半像素边缘。
4. 对称的左右侧壁可以镜像 UV。
5. 正面状态窗和药剂颜色不得镜像到错误方向。
6. 顶盖内外表面必须使用不同 UV 区域。
7. 检查 UV 岛之间至少留出必要边界，避免 Minecraft mipmap 串色。
8. 贴图保存为 PNG，保持最近邻像素，不使用有损压缩。

## 11. 打开与关闭模型的制作方式

### 11.1 主工程

主 `.bbmodel` 中保留完整层级和两种姿态：

- `closed`：`lid.rotation.x = 0°`；
- `open`：`lid.rotation.x = -70°`。

保存一个建模完成后的主检查点，再派生导出文件。

### 11.2 关闭模型

复制主工程为关闭版本：

```text
syringe_bag_3d_closed.bbmodel
```

要求：

- 顶盖为 0°；
- 药剂组可以保留但应被盖板完全遮挡；
- 不得删除内部结构后又改变外部尺寸。

### 11.3 打开模型

复制主工程为打开版本：

```text
syringe_bag_3d_open.bbmodel
```

要求：

- 顶盖绕指定枢轴旋转约 -70°；
- 药剂组可见；
- 正面外壳不旋转；
- 挂环、卡扣和状态窗位置与关闭模型完全一致。

如果最终渲染管线只接受原版元素旋转角度，不能直接把 70° 写入普通 item JSON。应选择以下一种方式：

1. 使用自定义物品/Curios 渲染器读取主模型；
2. 将打开姿态烘焙为独立静态几何；
3. 暂时使用原版允许的 `-45°` 预览角度，但不得错误声称它与三视图完全一致。

## 12. 手持与佩戴显示

### 12.1 物品栏

物品栏不使用三维模型，继续使用：

- `syringe_bag.png`；
- `syringe_bag_open.png`。

不要为 GUI 图标渲染三维模型后再缩小，这会破坏已经确认的 16×16 图标。

### 12.2 手持

手持时使用关闭三维模型。建议以以下值作为首次测试起点，实际数值需在游戏中微调：

```text
第三人称右手：
rotation    = [0, -90, 10]
translation = [0, 2, 1]
scale       = [0.55, 0.55, 0.55]

第一人称右手：
rotation    = [0, -90, 5]
translation = [1.5, 2, 0]
scale       = [0.65, 0.65, 0.65]
```

左手显示应镜像位置，不应镜像状态窗在模型本体上的物理位置。

### 12.3 腰带佩戴

腰带佩戴时：

- 模型水平中心与玩家躯干中心对齐；
- `back_panel` 面贴近玩家身体；
- 正面朝外；
- 宽度约等于玩家躯干视觉宽度；
- 推荐从统一缩放 `0.6–0.7` 开始测试；
- 不允许模型埋入腿部或悬空离开腰部；
- 两侧挂环应位于腰带附近。

不要把佩戴缩放直接烘焙进方块坐标。通过渲染变换调整，以便手持模型与佩戴模型共享同一几何。

## 13. Blockbench 实际操作顺序

1. 新建 Generic Model，设置 32×32 贴图。
2. 建立完整组层级。
3. 按坐标表建立五块中空盒体外壳。
4. 在正交正视图中检查 12:7 的宽高关系。
5. 在正交右视图中检查 4 单位厚度。
6. 添加底部修边和顶部开口前沿。
7. 建立 `lid` 组并首先确认枢轴 `(8,10.75,6)`。
8. 添加顶盖外壳、内嵌面和方形铰链。
9. 测试顶盖从 0° 到 -70° 的旋转，确认无穿模。
10. 添加中央卡扣和青色状态窗。
11. 用三块方体分别建立左右空心挂环。
12. 添加五个槽位和五个两段式安瓿。
13. 创建 32×32 材质，先画大面积外壳，再画硬件和药液。
14. 逐面分配 UV，保持整数像素边界。
15. 切换到无透视正交视图，与三视图逐项对照。
16. 保存主工程检查点。
17. 派生关闭与打开版本。
18. 分别检查手持预览和腰部佩戴预览。
19. 导出前检查隐藏面、重叠面、未使用纹理和错误 UV。

## 14. 必须进行的三视图验收

### 正视图

- 总宽明显大于总高；
- 顶盖关闭时只是一条窄顶部结构；
- 卡扣位于正中；
- 状态窗位于右下；
- 两侧挂环严格镜像；
- 打开后只出现一排五个药剂。

### 右视图

- 盒体厚度约为宽度的三分之一；
- 卡扣只在正面边缘形成薄突起，不能出现在侧面中央；
- 状态窗不应成为侧面上的大青色方块；
- 能看见一个侧挂环；
- 打开状态能明确看出后上方铰链和顶盖旋转。

### 俯视图

- 能分辨贴身背面与朝外正面；
- 顶盖宽度与盒体宽度一致；
- 左右挂环位置对称；
- 打开状态中五个药剂沿 X 轴直线排列；
- 药剂没有形成第二排。

## 15. 几何与资源验证清单

建模完成后逐项确认：

- [ ] 没有球体、圆柱、曲面或倒角；
- [ ] 除顶盖外没有斜置方块；
- [ ] 外壳宽 12、高约 7、厚 4；
- [ ] 后表面为贴身面，正面为 +Z；
- [ ] 正面不会打开；
- [ ] 顶盖枢轴准确位于后上沿；
- [ ] 打开和关闭模型使用相同顶盖尺寸；
- [ ] 五个药剂只有一排；
- [ ] 左右挂环严格镜像且中间为空；
- [ ] UV 全部落在整数像素；
- [ ] 顶盖内外使用不同 UV；
- [ ] 贴图为 32×32 PNG；
- [ ] 贴图没有抗锯齿和半透明脏边；
- [ ] 没有 Z-fighting 共面闪烁；
- [ ] 没有隐藏在实心盒体内的大量无用面；
- [ ] 物品栏仍使用二维图标；
- [ ] 三维资源没有覆盖 `syringe_bag.json` 的二维物品模型；
- [ ] 打开状态在正视、侧视和俯视中都与三视图一致。

## 16. 禁止 AI 自行发挥的内容

AI 建模时不得擅自加入：

- 医疗十字、文字、编号或品牌标志；
- 霓虹灯条；
- 圆形按钮；
- 金属铆钉和螺丝微几何；
- 布料褶皱、皮革带或军用战术织带；
- 第二层药剂；
- 向下翻开的正面门；
- 横放手提箱结构；
- 圆柱形药瓶；
- 高分辨率噪点、划痕或写实磨损；
- 与注射枪不一致的高饱和炫酷科幻装饰。

模型的识别度应来自宽扁轮廓、顶部窄盖、中央卡扣、右下状态窗、两侧挂环和一排彩色药剂，而不是额外复杂度。
